# Glimpse Development Guidelines

## Project Overview
Glimpse is a social memory-sharing platform where users capture daily moments and transform them into meaningful monthly memories.

## Tech Stack
- Next.js 15
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Vercel

## Development Rules

- Write clean, production-ready TypeScript.
- Use reusable React components.
- Follow Next.js App Router best practices.
- Keep components modular.
- Handle loading, error, and empty states.
- Write secure database queries.
- Validate user inputs.
- Do not add unnecessary dependencies.
- Keep mobile-first responsive design.

## Code Style

- Use meaningful variable names.
- Avoid duplicate code.
- Keep files organized.
- Add comments only for complex logic.

## Before Adding Features

Always:
1. Understand the requirement.
2. Plan database changes.
3. Consider security.
4. Test functionality.
