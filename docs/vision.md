# Glimpse Vision

## What is Glimpse?

Glimpse is a social memory-sharing platform where users capture and share meaningful moments from their daily lives.

A "Glimpse" can be:

* A photo
* A memory
* An achievement
* A thought
* A special moment

## Mission

Help people preserve everyday moments and transform them into lasting memories.

## Core Features

### MVP

* User Authentication
* Create Glimpse
* Image Upload
* Feed
* User Profiles
* Reactions
* Comments

### Future Features

* Follow Users
* Notifications
* Search
* AI-powered Monthly Recaps
* Automatic Monthly Collages

## Long-Term Goal

At the end of every month, users receive a beautiful visual summary of their memories, helping them relive important moments and track their personal journey.
